Google OAuth — Sign in with Google
The Sign In modal has a Google button styled but it does nothing when clicked. Need: npm install passport passport-google-oauth20, a Google Developer Console project, and callback routes. Most users expect this — many will not register with email/password.
critical
Socket.io — Real-time WebSockets
Live reading rooms show "247 readers" but it's a hardcoded number. The author "writing now" badge is always on. The live reader counter on the homepage uses a random number generator. Socket.io makes all of these genuinely real-time. Need: npm install socket.io.
critical
Email (SMTP) — Welcome, reset, announcements
SMTP_HOST, SMTP_USER, SMTP_PASS are empty in .env. Forgot password generates a token but the email never arrives. Announcements sent from admin never reach users by email. Fix: add Gmail SMTP credentials or a free SendGrid account to .env.
important
File uploads — Book covers & author photos
Authors can type a cover image URL but cannot upload an actual image file. No POST /api/upload endpoint exists. Need: npm install multer + either AWS S3 or Cloudinary (free tier available) to store uploaded images.
important
Stripe Connect — Author payouts
Readers pay via Visa and the money arrives in the platform Stripe account. Authors never receive their 95%. Stripe Connect lets each author link their own bank account. The author_payouts table in the schema is waiting — no code exists yet.
