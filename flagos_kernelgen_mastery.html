What is FlagOS?
FlagOS — the full ecosystem

FlagOS is a unified, open-source AI system software stack built for multi-chip AI hardware. It was jointly started by over 10 organizations including chip companies, AI research labs (BAAI), and system manufacturers. Its goal: let developers write AI software once and run it across many different GPU/NPU chips without rewriting code for each one.

Open source Multi-chip AI Apache 2.0 license
FlagGems core library

High-performance operator library written in Triton. Over 100 operators, supports 7 hardware backends. This is the library KernelGen contributes generated kernels into.

FlagTree compiler

Unified compiler for multiple AI chips. Fork of triton-lang/triton with multi-backend support.

FlagScale large models

End-to-end framework supporting the full lifecycle of large AI models — training, deployment, optimization.

KernelGen our focus tonight

AI-powered automatic Triton kernel generation, optimization, and testing tool. The key tool for the competition.

What is KernelGen — clearly explained
What it actually does

KernelGen lets you describe a math operation (called an operator) in plain language or as a definition, then it automatically writes, tests, and optimizes the low-level GPU code (a Triton kernel) for that operator — across many chip types. Think of it like: "you tell it what computation you need, it writes the fastest possible code for it on any chip."

KernelGen workflow (generate → optimize → test → deploy)

The full pipeline KernelGen automates:

1
Define the operator
Describe what math operation you need — in natural language or as a formal definition on the web platform
2
Generate kernel
KernelGen's AI writes Triton kernel code automatically — multiple candidate versions
3
Autotune & optimize
Runs performance tests, finds fastest configuration for your hardware target
4
Verify correctness
Automated correctness tests — 100% pass rate required before contribution
5
Deploy / contribute
Contribute the kernel to FlagGems, or use it directly in your own project via MCP or Skills

Tonight's demo plan using KernelGen web platform
The web platform requires NO installation. Open a browser, sign up, and start generating kernels immediately. This is your fastest path to a demo tonight.
1
Go to the platform and sign up
Open your browser and go to kernelgen.flagos.io — create an account (it's free). Check the browser requirements page first to confirm your browser is supported.
kernelgen.flagos.io
2
Understand what to generate for your demo
For an exam monitoring demo, you want to generate an operator that does a core computer vision computation — for example a convolution kernel (used in image processing and motion detection) or a softmax operator (used in classification). These are real operations inside any CV model.
3
Use a predefined use case first
The platform has prebuilt use cases for beginners. On your first login, click "Generate Kernels through predefined use cases" — this shows KernelGen working end-to-end without you needing to define the operator yourself. Perfect for a demo.
4
Then try your own operator definition
In the web UI, describe your operator using natural language. For example: "A 2D convolution operator for processing grayscale video frames to detect motion between frames". KernelGen will generate the Triton kernel code automatically.
5
View results and select optimal kernel
KernelGen generates multiple kernel candidates. The platform shows you correctness test results and speedup ratios. Select the best one and show this screen to your leader — it proves the tool is working and generating optimized code.
6
Optional: connect MCP to VSCode for advanced demo
If you have VSCode installed, you can connect KernelGen's MCP server to it. Get your token from the web platform, then configure VSCode to use the MCP toolkit. This lets you call KernelGen from inside your code editor — very impressive to show.
1. Get token: kernelgen.flagos.io → account → API token 2. In VSCode: install MCP extension 3. Add KernelGen MCP server config with your token 4. Use natural language in VSCode to generate kernels
