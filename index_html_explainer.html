What index.html does in the Global BookShelf project — it is the project launchpad that links all pages together

🗂️
index.html — the project launchpad / table of contents
This page is not part of the website that users see. It is a private developer page — a visual map of everything you have built, so you can click into any page quickly during development. Think of it as the cover page of your entire project.
Simple analogy: Imagine you are writing a textbook. The index.html is the table of contents at the front — it lists every chapter and lets you jump to any page. The chapters themselves (global-bookshelf.html, ai-reading-soul.html, etc.) are the actual content. The table of contents is not a chapter — it just helps you navigate.
What it contains
5 page cards
Each card shows the page name, icon, description, feature list, and a clickable "Open page →" button that goes directly to that page.
What it does not contain
No real features
No API calls, no user data, no database queries. It is a static HTML page that only has links and descriptions of what you built.
The status bar at the top
Build progress tracker
Shows 5 pages built, 29 DB tables, 62 indexes, 4 AI features — a quick dashboard of how far the project has come. For your reference only.
The "What we build next" section
Roadmap cards
6 cards listing what still needs to be built — backend API, mobile app, payments, AI engine etc. A reminder of what comes after.
