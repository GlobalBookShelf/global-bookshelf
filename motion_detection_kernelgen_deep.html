The 4 operators you will generate in KernelGen
According to the docs, each operator definition must include: operator name, function description, input parameters + data type, and output parameters + data type. Here are all four ready for you.
frame_difference_operator start here
Detects motion by computing pixel-level difference between two consecutive frames
Input: frame_t (Tensor[H,W,3], float32) — current frame frame_t1 (Tensor[H,W,3], float32) — previous frame Output: diff_map (Tensor[H,W], float32) — motion intensity per pixel
Exact prompt to paste into KernelGen web platform:
Operator Name: frame_difference_operator Function Description: Compute the absolute pixel-wise difference between two consecutive grayscale video frames to detect motion. For each pixel position (i,j), compute the mean absolute difference across the 3 color channels, then return a 2D motion intensity map. This operator is used in real-time student exam monitoring to identify movement between frames. Input Parameters: - frame_t: 2D tensor of shape (H, W, 3), dtype float32 — current video frame, pixel values normalized 0.0 to 1.0 - frame_t1: 2D tensor of shape (H, W, 3), dtype float32 — previous video frame, same shape and dtype Output Parameters: - diff_map: 2D tensor of shape (H, W), dtype float32 — per-pixel motion intensity score, range 0.0 to 1.0
gaussian_blur_2d_operator
Smooths the motion map to remove camera noise before thresholding
Input: input_map (Tensor[H,W], float32), kernel_size (int), sigma (float32) Output: blurred_map (Tensor[H,W], float32)
Exact prompt to paste into KernelGen:
Operator Name: gaussian_blur_2d_operator Function Description: Apply a 2D Gaussian blur filter to a single-channel float32 image tensor. The Gaussian kernel is computed from the given sigma value and kernel size. This smooths noise from the motion difference map in an exam hall video monitoring system, reducing false positives from camera sensor noise. Input Parameters: - input_map: 2D tensor of shape (H, W), dtype float32 — single-channel motion intensity map - kernel_size: integer scalar — size of the Gaussian kernel (e.g. 5 for a 5x5 kernel) - sigma: float32 scalar — standard deviation of the Gaussian distribution Output Parameters: - blurred_map: 2D tensor of shape (H, W), dtype float32 — Gaussian-smoothed motion map, same spatial size as input
motion_threshold_operator
Classifies each pixel as motion or no-motion using an adaptive threshold
Input: blurred_map (Tensor[H,W], float32), threshold (float32) Output: binary_mask (Tensor[H,W], int32) — 1=motion, 0=still
Exact prompt to paste into KernelGen:
Operator Name: motion_threshold_operator Function Description: Apply an element-wise threshold to a 2D motion intensity map to produce a binary motion mask. Each pixel value above the threshold is set to 1 (motion detected), values at or below are set to 0 (no motion). Used in exam hall student monitoring to isolate regions of suspicious movement from background stillness. Input Parameters: - blurred_map: 2D tensor of shape (H, W), dtype float32 — smoothed motion intensity map - threshold: float32 scalar — intensity threshold value (e.g. 0.1) Output Parameters: - binary_mask: 2D tensor of shape (H, W), dtype int32 — binary motion mask; 1 where motion is detected, 0 elsewhere
motion_score_softmax_operator
Converts raw region scores to suspicious/normal probabilities for the alert system
Input: region_scores (Tensor[N], float32) — N detected motion regions Output: probabilities (Tensor[N], float32) — normalized suspicion probability per region
Exact prompt to paste into KernelGen:
Operator Name: motion_score_softmax_operator Function Description: Apply the softmax function to a 1D tensor of motion region scores to convert raw activity scores into normalized probability values between 0 and 1. Each output value represents the relative suspicion probability for a detected motion region in an exam hall. Higher values indicate more suspicious behavior relative to other detected regions. Input Parameters: - region_scores: 1D tensor of shape (N,), dtype float32 — raw motion intensity scores for N detected motion regions Output Parameters: - probabilities: 1D tensor of shape (N,), dtype float32 — softmax-normalized suspicion probabilities; values sum to 1.0

Python integration — how your downloaded kernels connect to the webcam
After downloading all 4 kernels from KernelGen, this is the structure of your main application. The kernels drop straight in as Python functions.
import cv2, torch from frame_difference_operator import frame_difference_operator from gaussian_blur_2d_operator import gaussian_blur_2d_operator from motion_threshold_operator import motion_threshold_operator from motion_score_softmax_operator import motion_score_softmax_operator cap = cv2.VideoCapture(0) # 0 = laptop webcam prev_frame = None THRESHOLD = 0.15 # tune this for exam hall sensitivity while True: ret, frame = cap.read() frame_t = torch.tensor(frame / 255.0, dtype=torch.float32) if prev_frame is not None: # Pipeline — all 4 KernelGen operators in sequence diff = frame_difference_operator(frame_t, prev_frame) smooth = gaussian_blur_2d_operator(diff, kernel_size=5, sigma=1.0) mask = motion_threshold_operator(smooth, threshold=THRESHOLD) motion_pixels = mask.sum().item() scores = torch.tensor([motion_pixels], dtype=torch.float32) probs = motion_score_softmax_operator(scores) # Display alert label = "SUSPICIOUS" if probs[0] > 0.5 else "Normal" color = (0, 0, 255) if label == "SUSPICIOUS" else (0, 255, 0) cv2.putText(frame, label, (20,40), cv2.FONT_HERSHEY_SIMPLEX, 1.2, color, 2) cv2.imshow("Exam Hall Monitor - FlagOS KernelGen", frame) prev_frame = frame_t if cv2.waitKey(1) & 0xFF == ord('q'): break
