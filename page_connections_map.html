Why separate pages is the RIGHT design
Soul quiz
Takes 5 screens to complete — it cannot fit inside the homepage
The quiz has 5 full-screen steps: emotional needs → passage resonance → 6 reading dials → reading ritual → soul reveal with animated archetype, 14 dimension bars, and 6 book matches. This is its own experience. If it was inside the homepage the user would have to scroll past the world map to do the quiz — terrible experience.
Author page
Each author has their own page — like a profile page on Twitter
Robert Greene has a page. Adaeze Okonkwo has a page. You cannot put all author profiles inside the homepage — there are thousands of them. The homepage just links to whichever author the user clicks on. Exactly like how Instagram works — the feed links to profiles, the profiles are separate pages.
Book detail
Each book has its own page — like a product page on Amazon
The book detail page has a 3D cover, excerpt, character map, annotations, debate room, and ambient reading mode. There are 4.2 million books — each one needs its own URL. The homepage shows a grid of books, and clicking one opens that book's page. Exactly like Amazon shows product cards on the homepage, and clicking one opens the product page.
3 small connection fixes still needed
Soul quiz ending — after completing the quiz and seeing the soul profile, there is no "Go back to homepage" button. The user is stuck on the soul page. Need to add: a button that saves the soul profile and returns to global-bookshelf.html
Book detail → back to map — the breadcrumb says "Fiction / India" which links to the homepage, but it should link to the map with that genre/country already filtered. Need: href="global-bookshelf.html?genre=Fiction&country=IN"
Author universe nav — the nav says "Explore" but links to global-bookshelf.html instead of explore.html. Minor — already functional, just wrong destination.
